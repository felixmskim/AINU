# 학습 문서 안내

> 검토 메모 (2026-11-06): ① '학습방법.md' 이름으로 받았지만 내용은 학습 문서 3종의 안내다. `학습방법.md` 본문(설명하기·자유 노트·오답 분석 후 재시험의 실행 방법·효과·참고 자료)은 아직 공유되지 않음 ② 판별 소프트웨어 설계 링크의 파일명 오류 수정 ③ 챗봇 적용(학습 활동 대응표): 저장소 `docs/SPEC.md` §4.6.

학습 활동과 학습 수준 판별 로직을 별도 문서로 관리한다.

| 문서 | 관리 내용 |
|---|---|
| [학습 방법](학습방법.md) (미공유) | 설명하기, 빈 텍스트 파일에 자유 노트 작성하기, 오답 분석 후 재시험의 실행 방법·효과·참고 자료 |
| [학습 수준 판별 로직](학습수준_판별로직.md) | 입력, 분석 순서, 개념별 판정 기준, 확인 질문, 결과 형식과 예시 |
| [판별 소프트웨어 설계](학습수준_판별로직_소프트웨어설계.md) | 시스템 구조, 데이터 모델, 조건·문맥 처리, 검증기, 판정 규칙, API와 검증 계획 |

학습 활동을 변경할 때는 학습 방법 문서를, 진단 기준이나 결과를 변경할 때는 판별 로직 문서를 수정한다.
구현 구조나 처리 절차를 변경할 때는 판별 소프트웨어 설계 문서를 수정한다.
