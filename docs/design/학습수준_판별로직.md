# 학습 수준 판별 로직 — 교육자용 근거 기반 설계

> 검토 메모 (2026-11-06): ① 소프트웨어 설계 문서 링크의 파일명 오류 수정 ② `학습방법.md` 는 아직 공유되지 않음(링크에 표시) ③ 이전 버전을 가리키던 표현('기존 2–5단계', '기존 문서는') 정리. 챗봇 적용 축소판은 저장소 `docs/SPEC.md` §4.3.

## 1. 목적과 적용 범위

자유 노트에서 관찰되는 증거를 바탕으로, 학습자가 무엇을 설명하거나 적용할 수 있는지 확인하고 다음 학습 활동을 결정한다. 학습 활동 자체는 [학습 방법](학습방법.md)(미공유)에서 관리한다.

**핵심 변경:** 노트와 모범 답안의 문장 유사도를 판단하는 대신, 수업 목표에 맞춰 사전에 만든 평가 요소별로 증거를 확인한다. 기록이 없다는 사실과 잘못 알고 있다는 증거를 구분한다.

이 문서의 상태 코드·분기·확률 예시는 공식 평가 원리를 자유 노트에 적용한 자체 설계안이다. 공식 기관이 이 자동 판별 절차나 정확도를 인증한 것은 아니다. 실제 수업의 학년·성취기준·배운 범위에 맞게 교과 담당자가 기준을 검토해야 한다.

## 3. 판별 전에 교육자가 준비할 평가 기준표

노트부터 읽고 즉석에서 정답 기준을 만들지 않는다. 아래 항목을 학습 범위별로 작성하고 검토한다.

| 항목              | 작성할 내용                                                |
| --------------- | ----------------------------------------------------- |
| 학습 목표·출처        | 학년, 과목, 단원, 성취기준 또는 수업 목표, 교재의 쪽·절                    |
| 수행 요구           | 정의하기 / 비교하기 / 이유 설명하기 / 계산하기 / 새 상황에 적용하기 중 실제로 확인할 것 |
| 평가 요소 ID        | 한 번에 확인할 수 있는 작은 수행 단위의 식별자                           |
| 필수 증거           | 학생의 말·식·풀이에 어떤 내용이 있어야 이 요소를 인정하는지                    |
| 인정 표현           | 교과서식 답안 외에 인정할 일상어·동치식·예시                             |
| 불인정·반대 증거       | 명백히 틀린 관계, 잘못된 계산, 조건과 맞지 않는 적용 사례                    |
| 문맥에서 복원할 수 있는 것 | 소제목·기호 정의·바로 이어지는 풀이에서 명시된 대상과 조건                     |
| 후속 과제           | 이 요소만 확인할 질문과 기대 답변·오답의 판정 기준                         |

정의·원리·조건·적용을 모든 개념에 일괄 요구하지 않는다. 교과와 수업 목표에 필요한 요소만 만든다. 역사에서는 주장과 사료의 연결, 언어에서는 용법과 문맥 등으로 요소를 달리한다.

## 4. ‘표현이 달라도 같은 의미’의 판정 방법

### 4.1 비교 대상은 문장 전체가 아니라 평가 요소

각 요소에 대해 다음을 확인한다.

1. **대상:** 무엇에 대한 설명인지 특정할 수 있는가?
2. **관계:** 같음·증가·감소·포함·인과·독립 등 목표에서 요구하는 관계가 표현됐는가?
3. **방향과 범위:** 원인과 결과가 뒤바뀌거나, ‘일부’가 ‘항상’으로 바뀌지 않았는가?
4. **필요 조건:** 해당 요소가 요구하는 조건이 문장이나 명시된 문맥에 있는가?
5. **반대 증거:** 같은 요소에 대해 충돌하는 설명이 함께 있는가?

필수 내용이 충족되면 어순·동의어·일상어 차이는 허용한다. 학생이 적지 않은 관계를 채점자가 대신 만들어 넣지 않는다. 기준표에 없는 새 표현은 곧바로 오답 처리하지 않고 교과 검토를 거쳐 인정 범위를 갱신한다.

### 4.2 예시: 독립의 의미를 설명하는 요소

이 예시에서는 ‘첫 사건의 발생 여부가 두 번째 사건의 확률을 바꾸지 않는다’를 인정 기준으로 정한다. 정식 정의·증명까지 요구하는 별도 목표와는 구분한다.

| 학생 표현                                 | 요소별 판정    | 이유                                    |
| ------------------------------------- | --------- | ------------------------------------- |
| “첫 번째 결과를 알아도 두 번째 확률은 그대로다.”         | 충족        | 두 사건의 관계와 확률 불변이 표현됨                  |
| “첫 번째 결과 때문에 두 번째가 나올 가능성이 달라지지 않는다.” | 충족        | 일상어지만 필요한 관계를 보존함                     |
| “독립 = 서로 영향 없음.”                      | 확인 필요: 축약 | 무엇이 변하지 않는지 명확하지 않음. 확률을 뜻하는지 질문으로 확인 |
| “독립은 두 사건이 같이 일어날 수 없다는 뜻.”           | 충돌        | 독립과 배반을 혼동하는 반대 증거가 있음                |
| “독립, 곱셈, 조건부확률.”                      | 확인 필요: 나열 | 용어는 있지만 관계를 설명하지 않음                   |

‘충족’은 해당 평가 요소의 증거가 있다는 뜻이며, 개념 전체를 숙달했다는 판정이 아니다.

## 5. 추상적인 항목을 관찰 가능한 기준으로 바꾸기

| 기존 표현  | 교육자가 확인할 구체적 증거                      | 확률 단원에서의 예                                  |
| ------ | ------------------------------------ | ------------------------------------------- |
| 정확성    | 기준표에 정한 사실·정의·식과 일치하는 주장 또는 계산       | 독립 사건에서 P(A∩B)=P(A)P(B)를 쓰고 실제 수치를 올바르게 대입함 |
| 원리와 관계 | 결론과 근거를 연결하는 설명 또는 정당한 풀이 단계         | 첫 추출 뒤 남은 공 구성이 변하므로 두 번째 빨강 확률이 변한다고 설명함   |
| 성립 조건  | 사용할 규칙의 전제를 식별하거나 조건이 다른 사례를 구별하는 수행 | 복원·비복원 추출에서 각 확률을 어떻게 정해야 하는지 구분함           |
| 적용     | 새 상황의 사건·조건을 식별하고 적절한 식을 선택해 실행하는 수행 | 주어진 공 구성을 사용해 비복원 추출의 두 번 연속 빨강 확률을 계산함     |

정답 수치만 있으면 그 계산 결과에 대한 증거만 인정한다. 풀이 원리나 조건 이해까지 자동 인정하지 않는다. 반대로 원리는 맞고 산술 계산만 틀렸다면 원리와 계산 오류를 별도로 기록한다.

## 6. 모호한 설명과 조건 생략을 구분하는 분기

### 6.1 문맥 복원 규칙

소제목, 학습자가 명시한 기호 정의, 해당 문장의 지시 대상이 분명한 앞뒤 설명·풀이를 함께 읽는다. 어떤 문장을 근거로 해석했는지 기록한다. 해당 문장과 다른 범위의 예시라는 사실만으로 조건을 소급해 넣지 않는다. 다른 개념의 먼 문장까지 연결해야 하거나 해석이 여러 개면 보류한다.

### 6.2 조건이 없는 문장을 처리하는 기준

| 상황                                            | 판정              | 후속 조치                                    |
| --------------------------------------------- | --------------- | ---------------------------------------- |
| “독립 사건” 소제목 아래에 “동시에 일어날 확률 = 각각의 확률의 곱”이라고 씀 | 그 문맥의 식은 충족     | 독립을 구별하는 능력은 별도 과제로 확인                   |
| 범위가 불분명한 메모에 “확률은 곱한다”라고만 씀                   | 확인 필요: 모호       | 어떤 사건·상황을 뜻했는지 질문                        |
| 일반적인 곱셈 법칙을 설명해 달라는 과제에 독립인 경우의 식만 제시         | 일반 법칙 요소의 증거 부족 | 일반 상황의 공식을 추가로 물음. 이미 적은 특수 사례는 별도 인정 가능 |
| “독립이 아니어도 항상 원래 확률끼리 곱한다”라고 명시                | 충돌: 잘못된 일반화     | 대조 사례에서 판단 근거 확인 후 교정                    |
| 비복원 추출에서 두 번째 확률도 처음과 같게 대입                   | 적용 요소에서 충돌      | 단순 전사·계산 실수인지, 조건 이해의 오류인지 설명 질문으로 구분    |
| 조건에 관한 내용 자체가 없음                              | 확인 필요: 미관찰      | 조건을 구별하는 과제 제시                           |

**노트의 생략은 관찰된 증거 부족이고, 명시적 일반화나 잘못된 적용은 반대 증거다.** 둘 다 학생의 지속적인 오개념으로 곧바로 확정하지 않는다.

### 6.3 모호함을 표시하는 구체적인 신호

- 대상 미정: “이것이 커진다”에서 ‘이것’이 무엇인지 특정되지 않음.
- 관계 미정: “독립과 곱셈은 관련 있다”에서 어떤 관련인지 적지 않음.
- 기준 미정: “확률이 크다”에서 비교 대상이나 수치가 필요한 목표인데 그것이 없음.
- 해석 다수: “영향 없음”이 사건의 발생 불가능성인지 확률 불변인지 구분되지 않음.
- 내부 충돌: 같은 조건에서 서로 반대되는 주장을 함께 적음. 이 경우는 단순 모호함과 별도로 충돌 표시.

축약어·화살표 자체는 오류 신호가 아니다. 예를 들어 “비복원 → 빨강 뽑은 뒤 빨강 비율 변화”처럼 대상과 관계가 복원되면 그 관계의 증거로 사용할 수 있다.

## 7. 기록 단위와 상태

평가 요소마다 아래 상태 하나를 붙인다. 요소 일부만 충족하면 요소가 너무 큰지 검토하고 분리한다.

| 코드  | 상태          | 필요한 근거                                    |
| --- | ----------- | ----------------------------------------- |
| E   | 충족 증거 있음    | 필수 내용이 학생 원문·풀이에서 확인되고 그 요소의 반대 증거가 없음    |
| X   | 충돌 증거 있음    | 같은 조건에서 기준과 어긋나는 명시적 주장·식·적용 또는 내부 충돌이 있음 |
| U   | 확인 필요       | 미작성·용어 나열·다의적 표현·필요한 연결 생략으로 결정할 증거가 부족함  |
| NA  | 이번 판별 대상 아님 | 학습 목표 밖이거나 이 과제로 확인하도록 설계하지 않은 요소임        |

각 판정에는 요소 ID, 학생 원문, 문맥 원문, 기준 자료 위치, 판단 이유를 저장한다. U에는 미작성/대상 불명/관계 불명/조건 미확인 등의 사유를 붙인다. E와 X가 함께 관찰되면 X로 표시하고 두 증거를 모두 남겨 추가 확인한다.

개념 전체를 요약할 때는 ‘정의 E, 조건 U, 적용 X’처럼 표시한다. U를 0점으로 환산하거나 임의의 백분율로 학습 수준을 만들지 않는다. X는 틀린 응답이 관찰됐다는 뜻이지 원인이 확정됐다는 뜻은 아니다.

## 8. 후속 질문은 어떤 증거를 얻을지 정한 뒤 제시

정답을 먼저 말하지 않는 것은 최초 독립 수행을 보존하기 위한 이 설계의 운영 원칙이다. 질문의 문구 자체가 힌트가 될 수 있으므로, 최초 노트와 질문 후 답변은 구분해 기록한다.

| 확인할 요소       | 질문                                                                                | 답변 판정 기준                                                        |
| ------------ | --------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| 축약된 독립 정의    | “‘영향 없다’고 했는데 무엇이 변하지 않는다는 뜻인가요?”                                                 | 두 번째 사건의 확률이 첫 사건의 발생 여부에 따라 바뀌지 않는다고 설명하면 해당 요소 E              |
| 조건에 따른 전략 선택 | “빨강 2개·파랑 1개인 주머니에서 두 번 뽑습니다. 매번 다시 넣을 때와 넣지 않을 때, 두 번 모두 빨강일 확률과 풀이를 각각 적어 주세요.” | 복원 (2/3)×(2/3)=4/9, 비복원 (2/3)×(1/2)=1/3. 식 선택과 수치 계산은 별도 요소로 판정 |
| 풀이의 이유       | “첫 번째에 빨강을 뽑은 뒤, 다음에 빨강을 뽑을 확률을 어떻게 정했나요?”                                        | 남은 빨강 수와 전체 공 수를 근거로 1/2를 설명하면 그 관계 요소 E                        |

선택지만 고른 답은 선택 수행에 대한 증거다. 이유 설명 목표가 있으면 설명을 추가 수집한다. 답변이 없으면 U를 유지하며, 같은 오류를 다시 보였을 때도 확인된 오류 유형까지만 기록한다.

## 9. 실행 순서

1. 학습 목표를 선정하고, 요소별 필수 증거·인정 표현·오류 사례·후속 질문을 교과 담당자가 검토한다.
2. 노트의 각 문장·공식·예시를 평가 요소 ID에 연결하고, 판단에 사용한 원문과 소제목·기호 정의를 함께 기록한다. 연결 근거가 없으면 해당 요소는 U로 둔다.
3. 요소별로 대상·관계·방향·조건을 기준표와 대조한다. 실제로 적힌 의미만 인정한다. 필수 증거 충족은 E, 명시적 반대 증거는 X, 해석 불명이나 미작성은 U로 구분한다.
4. 요소별 판정과 근거를 기록한다. 정의·조건·적용을 합쳐 하나의 인상 점수로 처리하지 않는다. 기준 밖의 표현이나 해석 충돌은 교과 검토로 넘긴다.
5. U와 X의 원인을 구별할 과제를 선택한다. 정답을 알려주기 전에 질문하고, 답변을 사전에 정한 기준에 따라 다시 판정한다. 최초 노트와 질문 후 수행을 각각 보존한다.
6. 확인된 부족 요소를 보충하고 노트 수정·재시험으로 연결한다. 교정·힌트 이후의 수행은 독립 수행과 구분한다.

## 10. 예시 노트 판별

```text
확률 곱셈
두 사건이 같이 일어날 확률은 각각 확률 곱하기
동전 앞면 두 번 = 1/2 × 1/2 = 1/4
독립은 서로 영향 안 주는 것
```

이 예시에서는 공정한 동전을 독립적으로 두 번 던지는 상황을 수업에서 다루었다고 가정한다. 가정이 확인되지 않으면 예시 계산의 상황부터 추가 확인한다.

| 평가 요소                   | 최초 판정     | 이유                               |
| ----------------------- | --------- | -------------------------------- |
| 배운 동전 사례에서 두 번 앞면 확률 계산 | E         | 식과 결과가 확인됨. 새 상황 적용 능력까지 인정하지 않음 |
| 독립의 의미를 확률 불변으로 설명      | U: 축약     | ‘영향’의 의미를 추가 확인해야 함              |
| 독립인 경우와 아닌 경우의 식 선택 구별  | U: 조건 미확인 | 특수 상황을 메모한 것인지 일반화한 것인지 불분명함     |
| 조건부확률을 사용한 일반 곱셈 법칙     | U: 미작성    | 해당 내용을 적지 않았다는 사실만 확인됨           |

첫 문장의 조건 생략만으로 오개념을 의심하는 것은 이 문맥에서 과도한 판단이다. 대조 문제에서 비복원 상황에도 4/9를 쓰거나 ‘언제나 처음 확률을 곱한다’고 명시하면 그때 해당 수행의 X 증거를 기록한다. 반대로 비복원 상황에서 1/3을 구하고 남은 공 구성을 설명하면 관련 요소의 충족 근거를 얻을 수 있다.

일반 법칙까지 배운 범위라면 별도 요소로 확인한다: P(A)>0일 때 P(A∩B)=P(A)P(B|A). 독립이면 P(B|A)=P(B)이므로 P(A∩B)=P(A)P(B). 이 수학 예시는 설명용으로 작성했으며 공식 채점표의 문항을 인용한 것이 아니다.

## 11. 교육자가 판정의 일관성을 확인하는 절차

- 서로 다른 표현, 짧은 메모, 조건 생략, 명시적 오류, 올바른 식과 계산 실수가 섞인 실제 답안을 모은다.
- 교과 담당자들이 동일 기준표로 독립 판정한 뒤 요소별 불일치를 비교한다. 이 과정은 문서 검토 제안이며 현재 시행한 검증 결과는 아니다.
- 불일치가 난 지점을 필수 증거·문맥 범위·인정답안 예시에 반영한다. 동의어 목록만 늘리지 않는다.
- 자동 판별을 사용한다면 교사 판정과 비교해 E의 과잉 인정, X의 과잉 판정, U의 과다 발생을 각각 확인한다. 임의의 신뢰도 수치를 출력하지 않는다.
- 새 인정 표현이나 기준 변경은 버전을 남기고, 기존 결과에 미치는 영향을 확인한다.
